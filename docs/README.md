## 🎯 Цели и задачи  
### Проблема  
Нежелание долго сравнивать косметические средства и подбирать их для своего типа кожи и решения проблем с ней;
Отсутствие времени для полноценной консультации со специалистом и обследования проблем с кожей


### Решение  
Устройство сканирующее лицо человека, и выдающее на основе полученных данных рекомендацию по подбору косметики и предполагаемый результат после её применения.

- Разработка бизнес-плана
- Создание моделей анализа и рекомендаций по уходу за кожей и их интеграция
- Тестирование

# Проект: Телеграм-бот на Python

## 📌 Введение

Целью проекта является создание телеграм-бота для комфортного путешествия по Республике Карелия. 
Проект реализован на языке Python.    

---

## 🔍 Этапы исследования

На первом этапе были изучены:
- Создание и редактирование бота через @BotFather
- Создание кнопки и обработчика нажатия


Использовались:
- [Документация Python-telegram-bot]([https://docs.python-telegram-bot.org/en/stable/index.html])

---

## 🛠 Этапы разработки

1. **Создание бота** через @BotFather с настройкой.
2. **Создание скрипта и привязка через токен** 
3. **Реализация меню:**
   - Кнопки "Что посмотреть", "Где купить сувениры", "Где остановиться на ночь".
   - В каждом разделе меню еще несколько вариативных кнопок, а также кнопка выхода в главное меню.
   - После нажатия на конечную кнопку выбора определенного объекта появляется карточка с полезной информацией в зависимости от контекста.

def main():
    try:
        # Создаем приложение
        application = Application.builder().token('7784053804:AAE6S1ZLbKJyAN8plFQjmky8nTXsgkXszNo').build()

        # Добавляем обработчики
        application.add_handler(CommandHandler("start", start))
        application.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, handle_message))
        
        # Добавляем обработчик ошибок
        application.add_error_handler(error_handler)

        logger.info("Бот запускается...")
        # Запускаем бота
        application.run_polling(allowed_updates=Update.ALL_TYPES)
    except Exception as e:
        logger.error(f"Критическая ошибка при запуске бота: {e}", exc_info=True)
